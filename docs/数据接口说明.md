# 小米手环 11 云端健康数据 接口说明（脱敏）

> 本文档描述本项目调用的**小米健康云 API**（`hlth.io.mi.com`）的登录链路、签名算法与数据字段字典。
> 所有示例数据均已脱敏/虚构，**不代表任何真实用户数据**。
> 仅供学习研究，接口可能随官方调整而变化。

---

## 1. 登录链路（免短信验证）

小米账号体系（`account.xiaomi.com` / `sts.api.xiaomi.com`）：

1. `serviceLogin?sid=miothealth&_locale=en_US` → 获取登录表单参数（qs、_sign 等）
2. `serviceLoginAuth2`（hash = MD5(密码) 大写）→ 返回 location（STS 跳转地址）
3. GET location（STS，**不带 clientSign**）→ 从响应 cookie（`sts-hlth.io.mi.com` 域）精确提取：
   - `userId`、`cUserId`、`serviceToken`
4. **固定设备指纹（deviceId）** 可免短信验证；换新指纹可能触发短信验证（提示先在小米运动 App 登录一次）

关键点：

- 多域 cookie 同名（`userId` 等），必须按域精确取值，否则会 `CookieConflictError`
- 密码只用于本次登录，服务端返回的令牌（serviceToken）持久化用于后续请求

## 2. 数据请求签名（mi_crypto）

| 项 | 值 |
|---|---|
| 请求头 | `UA=Android-16-3.55.0i-google-Pixel 4`、`region_tag=cn` |
| Cookie | `cUserId + serviceToken + userId + locale=en_us` |
| 签名 | `nonce = generate_nonce(0)`；`signed = mi_encrypt_params(method, signing_path=path, params={"data": json.dumps(params, separators=(",", ":"))})` |
| 传参 | **GET 参数放 URL，POST 放 body**；参数必须打包进 `data` JSON 字符串（直接传 dict 会 401 auth err） |
| 响应 | 去除 `&&&START&&&` 头后 `mi_decrypt_response` 解密；`code=0` 成功 |

## 3. 核心接口

| 接口 | 方法 | 用途 |
|---|---|---|
| `/app/v1/source/get_source_list` | POST | 绑定设备列表 |
| `/app/v1/data/get_aggregated_fitness_data_by_time` | GET | 按天聚合：steps / sleep / heart_rate / spo2 / calories / intensity / valid_stand |
| `/app/v1/data/get_fitness_data_by_time` | GET | 逐点明细：heart_rate / spo2 / stress |
| `/app/v1/data/get_sport_records_by_watermark` | GET | 运动记录（watermark 分页） |
| `/app/v1/data/get_latest_fitness_data` | GET | 最新快照（本项目实测报 code=-8 invalid params，参数未解，可跳过） |

## 4. 数据字段字典

### 通用字段（每条记录）

| 字段 | 说明 |
|---|---|
| `time` | unix 秒（东八区），聚合数据按自然日 0 点对齐 |
| `value` | JSON 字符串，内嵌该指标实际数据 |
| `watermark` | 数据游标（分页续取） |
| `source_sid_list` | 数据来源（`hlth.gen_*`=云端综合/历史，`<sid>`=本手环） |
| `update_time` | 数据更新时间 |

### 聚合指标（value 内）

- **steps**：`{"calories":285, "distance":4197, "steps":7115}`（距离单位：米）
- **calories**：`{"calories":339}`（总消耗，千卡）
- **valid_stand**：`{"count":14}`（站立次数，达标 ≥12）
- **sleep**：
  - `total_duration` / `sleep_deep_duration` / `sleep_light_duration` / `sleep_awake_duration`（分钟）
  - `sleep_score`（0-100）、`long_sleep_evaluation` / `day_sleep_evaluation` / `sleep_stage`
  - `avg_hr` / `avg_spo2`（睡眠期间均值，0=未测）
  - `segment_details[]`：分段记录（`bedtime` / `wake_up_time` unix 秒、`duration` 分钟、`timezone` 32=东八区、深睡/浅睡/醒来时长）
- **heart_rate**：`avg_hr`（日均）、`avg_rhr`（静息）、`latest_hr`、各心率区间时长（fat_burning/aerobic/anaerobic/extreme，分钟）、`abnormal_hr_count`
- **spo2**：`avg_spo2` / `max_spo2` / `min_spo2` / `lack_spo2_count` / `latest_spo2`
- **intensity**：运动强度时长（分钟）

### 逐点明细

- 每条 `value` 内：`{time, bpm}` / `{time, spo2}` / `{time, stress}`，间隔约 10 分钟
- `zone_offset: 28800`、`zone_name: "Asia/Shanghai"`
- 仅在手环采集后的最近几天有值

### 运动记录（workouts）

- `key` / `category`：类型（如 `outdoor_riding` 户外骑行）
- `calories`、`distance`（米）、`duration`（秒）、`avg_hrm`（平均心率）、`end_time`、起止坐标等
